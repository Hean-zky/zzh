## 文件说明

| 文件或目录 | 内容 |
| --- | --- |
| `index.html` | 个人主页结构和内容 |
| `styles.css` | 参考个人数据库式主页重写的响应式样式，支持日间/夜间主题 |
| `script.js` | 主题切换、项目详情弹窗和实物照片自动展播 |
| `头像.jpg` | 主页头像 |
| `实物展示` | 8 张实物样机照片 |
| `图片展示` | 三维模型展示图片 |
| `第一版-最终版本-step` | STEP 总装和零件文件 |

SolidWorks 2026 版本的 `.SLDASM` 和 `.SLDPRT` 源文件位于独立仓库：[AIChongZhi/mltwq](https://github.com/AIChongZhi/mltwq)

## 本地预览

直接打开 `index.html` 即可查看静态页面；也可以使用任意静态文件服务器从仓库根目录启动。
